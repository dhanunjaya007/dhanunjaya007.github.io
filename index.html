// Key Projects

Things I've built.

GitHub
Object Detection in Mixed Reality
End-to-end pipeline for precision industrial assembly guidance on Microsoft HoloLens 2. Built a synthetic dataset of 8 V-Lock components with real-time augmentation for occlusion-heavy scenarios. Applied hardware-aware INT8 post-training quantization on YOLOv8n and deployed via Unity Sentis runtime.
Computer Vision Mixed Reality YOLOv8n INT8 Quantization Unity Sentis
🪐
GitHub
Crater & Boulder Detection
Object detection for planetary surface features using YOLOv8n. Fine-tuned on a custom annotated dataset with hyperparameter optimization and data augmentation. Deep understanding of YOLO backbone, neck, and detection head architecture.
Computer Vision YOLOv8n Data Augmentation

Kronos Discord Bot
AI-powered team management bot integrating OpenRouter API with LLaMA, DeepSeek, Gemini, and Mistral. Activity tracking across IDEs with 30+ metrics in PostgreSQL. NLP-based reminder system with automated notifications.
NLP LLM Integration PostgreSQL OpenRouter API
